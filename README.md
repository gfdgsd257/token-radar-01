Token launch radar: ranks 178 pre-token DeFi protocols by implied launch value, scored from the sealed DefiLlama snapshot (758 protocols, as of 2026-11-14). Each protocol gets a category multiple, a growth factor and an age curve, plus an 8-step farm plan; the result is a static, no-network dashboard with a per-protocol dossier.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```

The snapshot (`input/snapshot.json`) comes from the competition kit and is not committed to this repo. Node 22+ required.
